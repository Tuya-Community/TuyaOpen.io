如果在使用 TuyaOpen IDE 时遇到问题，可以通过反馈入口提交诊断信息。

1. 点击 IDE 左下角的气泡反馈图标。
2. 按照页面提示依次填写反馈信息，需要诊断的信息会自动采集。
3. 完成填写后提交反馈。
