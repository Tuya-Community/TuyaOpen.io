## 프로젝트 개요

Tuya T5AI 보드에 내장 된 동적 조명 효과 안경의 쌍 : 프레임은 음악의 비트에 반응하고 분위기와 일치하기 위해 색상 온도를 이동, 파티 및 기타 소셜 설정을 볼 수 빛으로 비 verbal cues를 돌립니다. 보드의 실시간 리듬 감지는 사용자 정의 조명 계획 - 친밀감에 대한 따뜻한, 차분한 - LAN 링크를 통해.

## 주요 특징

- 동적 빛 효과 음악 비트와 동기화
- 다른 사회 환경을 위한 Customizable 빛 계획
- 색 온도 변화를 통한 감정적 시뮬레이션
- 불쾌함과 평온함을 위한 따뜻한 빛
- 시각적 피드백을 통한 사회적 상호 작용
- 실시간 리듬 검출 및 응답

## 기술 스택

- **TuyaOpen Framework **: 클라우드 기반 멀티 모듈 기능을 갖춘 AIoT 개발 플랫폼 완료
- ** 하드웨어 **: Tuya T5AI 회사소개
- **통신**: LAN 통신, 클라우드 연결과 직렬 통신
- **Software**: 클라우드 AI 통합을 통한 Embedded 소프트웨어 및 하드웨어 개발
- **AI Processing**: TuyaOpen을 통한 클라우드 기반 LLM 통합
- **Design**: PPT, 렌더링 기술


## 빠른 시작

1. Tuya T5AI 이사회 개발 환경 설정
2. 가벼운 효력 체계를 형성하십시오
3. 음악 Beat Detection 알고리즘 구현
4. LAN 통신 프로토콜 설정
5. 소셜 시나리오에 대한 다른 빛 구성
6. 감성적인 시뮬레이션 기능
7. 소셜 환경에서 배포 및 테스트
