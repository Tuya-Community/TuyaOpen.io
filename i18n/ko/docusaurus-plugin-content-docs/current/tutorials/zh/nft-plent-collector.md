## 프로젝트 개요

BSC와 Injective의 On-chain 자산으로 채굴되는 플랜트-NFT 프로젝트는 Zhipu AI 이미지 인식 서비스를 통해 실제 식물을 분류하고 컬렉션과 물리적 상호 작용을 위한 임베디드 디스플레이를 제공합니다. 스택은 React/TypeScript frontend, Python FastAPI 백엔드, Solidity smart contracts, 그리고 하드웨어 디스플레이를 통해 NFT 상태를 실시간으로 반영합니다.

## 주요 특징

- 플랜트 NFT 채굴 및 관리
- 이미지 인식 및 식물 분류
- 토큰 경제 및 거래 시스템
- 멀티체인 지원(BSC, Injective)
- 현대 웹 공용영역
- AI 기반 플랜트 식별
- Smart Contract 통합

## 기술 스택

- **프론트엔드**: React 18, TypeScript, Vite, Tailwind CSS, Axios
- ** 백엔드 **: Python, FastAPI, Docker
- **AI**: Zhipu AI API
- **블록체인 **: Solidity, Hardhat, Web3.js
- **네트웍스**: BSC 네트워크, 인젝티브 네트워크
- **Embedded**: 물리적 시각화 및 NFT 상호 작용을 위한 디스플레이 통합
- ** 인터랙션 **: 실시간 NFT 상태 동기화, NFT 디스플레이 및 전환을위한 물리적 버튼 / 터치 컨트롤

## 빠른 시작

1. 저장소를 복제하고 개발 환경을 설정
2. frontend 및 backend에 대한 의존성 설치
3. 블록체인 네트워크 구성 (BSC, Injective)
4. AI API 자격 설정
5. 스마트 컨트랙트 배포
6. 자주 묻는 질문
7. NFT 채굴 및 거래 기능 테스트
