문제가 발생하면 TuyaOpen IDE의 피드백 항목을 사용하여 진단 정보를 제출하세요.

1. IDE 왼쪽 아래의 말풍선 피드백 아이콘을 클릭합니다.
2. 화면의 안내에 따라 양식을 작성합니다. 필요한 진단 정보는 자동으로 수집됩니다.
3. 피드백을 제출합니다.
