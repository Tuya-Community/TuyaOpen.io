## 유지 관리 계획
### TuyaOpen OS 코어(C/C++)
TuyaOpen은 안정성과 지속적인 개선을 위해 체계적인 유지 관리 계획을 따릅니다.

- **활발한 개발**: 매일 코드를 커밋하며 지속적으로 개발합니다.
- **버그 수정**: 심각한 버그는 24~48시간 이내에 해결합니다. [GitHub Issues](https://github.com/tuya/TuyaOpen/issues)를 통해 문제를 신고하고 피드백을 제공할 수 있습니다.
- **기능 업데이트**: 2주마다 새로운 기능을 릴리스합니다.
- **주요 릴리스**: 중요한 새 기능을 포함한 메이저 버전을 분기마다 릴리스합니다.

### 새로운 기능 요청
프로젝트에 대한 제안이 있나요? [토론에 참여](https://github.com/tuya/TuyaOpen/discussions)해 주세요.
- **새 칩 지원**: Tuya는 커뮤니티 수요, 제품 로드맵 우선순위 및 기술적 실현 가능성을 바탕으로 새 칩 지원을 지속적으로 검토하고 추가합니다.
- **새 주변 장치 및 드라이버 지원**: R&D 팀은 새 드라이버를 적극적으로 통합해 지원 디바이스와 주변 장치의 종류를 꾸준히 확장합니다(정기적으로 업데이트). **커뮤니티 파트너도 디바이스 드라이버나 기타 기능 구성 요소를 기여해 생태계에 참여할 수 있습니다.**
- **서드파티 라이브러리(libs) 지원**: Tuya는 오픈 소스 라이선스를 준수하는 서드파티 라이브러리의 기여를 환영하고 커뮤니티 공동 제작을 장려합니다. 기여된 모든 라이브러리는 오픈 소스 준수 요건을 충족해야 합니다. Apache License를 우선하지만, 라이선스 호환성을 확인하고 명시적으로 선언한 다른 라이선스의 라이브러리도 허용합니다.

## 플랫폼 지원 계획
### SDK 지원 계획
| SDK | 활동 수준(업데이트 주기) | 설명 |
|-----------------|------------------------|------|
| **C/C++** | 매우 활발함 - 매일 개발 | 주요 임베디드 플랫폼과 칩을 지원하며 지속적으로 최적화하고 확장합니다. |
| **Arduino** | 지원됨, 업데이트 느림 | Arduino IDE를 지원하고 Tuya T 시리즈 및 ESP 개발 보드와 호환되며 Tuya Cloud/AI SDK 버전 업데이트를 지속적으로 반영합니다. |
| **Lua** | 지원됨, 업데이트 느림 | 주요 Lua 플랫폼에 맞게 조정되어 다양한 임베디드 애플리케이션 시나리오에 적합합니다. |
| **MicroPython** | 계획됨, 아직 시작되지 않음 | ESP32 및 T5AI와 같은 주요 MicroPython 펌웨어와 개발 보드를 지원해 임베디드 시스템용 Python 개발 및 Tuya Cloud 연동을 제공할 예정입니다. |

### 칩 플랫폼 지원
Tuya 칩 플랫폼은 정기적으로 업데이트하고 유지 관리합니다.

| 칩 플랫폼 | 지원 상태 | 활동 수준(업데이트 주기) | 비고 |
|------------------|------------|------------------------|-------|
| **MCU T5AI** | ✅ 활성 | 매우 활발함 | 오디오, 비디오, 텍스트를 포함한 AI 멀티모달 상호 작용에 적합합니다. |
| **MCU T2/T3** | ✅ 활성 | 적극적으로 유지 관리 | AI 텍스트 LLM + IoT 기능에 적합하며 저전력 시나리오에 강점이 있습니다. |
| **MCU BK7231N** | ✅ 활성 | 정기적으로 유지 관리 | - |
| **MCU LN882H** | ✅ 활성 | 정기적으로 유지 관리 | - |
| **MCU ESP32 시리즈** | ✅ 활성 | 정기적으로 유지 관리 | - |
| **SoC ARM Cortex-A** | 🚧 베타 | 개발 중(`master` 브랜치에서 사용 가능) | 주로 네트워킹, Tuya IoT PaaS 클라우드 연결 및 클라우드 AI 기능을 지원합니다. 하드웨어 아키텍처가 MCU 시리즈와 크게 다르므로 주변 장치 통합을 위한 DTS 디바이스 트리를 직접 개발해야 합니다. |
| **SoC Raspberry Pi 5** | 🚧 베타 | 개발 중 | 주로 네트워킹, Tuya IoT PaaS 클라우드 연결 및 클라우드 AI 기능을 지원합니다. 하드웨어 드라이버 아키텍처가 MCU 시리즈와 다르므로 주변 장치 통합을 위한 DTS 디바이스 트리를 직접 개발해야 합니다. Raspberry Pi는 풍부한 주변 장치 생태계와 사전 정의된 40핀 확장 인터페이스를 제공하므로 클라우드 서비스에 연결하기 전에 공식 하드웨어 생태계 문서를 참고하는 것이 좋습니다. |
| **Ubuntu** | ✅ 활성 | 적극적으로 유지 관리 | 주로 네트워킹, Tuya IoT PaaS 클라우드 연결 및 클라우드 AI 기능을 지원합니다. |


## 개발 로드맵
### 할 일
- T5 시리즈 칩에 SMP CPU 아키텍처 지원을 활성화합니다.
- Raspberry Pi, Rockchip, Allwinner 등 주요 SoC 플랫폼으로 지원을 확장합니다.
- TuyaOpen DVP 카메라의 비디오 모달리티 기능을 최적화합니다.
- 서드파티 개발 보드 생태계와 파트너십을 구축합니다.
- 클라우드 API를 AI SDK 3.0 사양으로 업그레이드합니다.
- 공식 포털에 클라우드 개발 튜토리얼을 게시합니다.
- 완전한 T5 하드웨어 데모를 포함한 Tuya Pocket 오픈 소스 프로젝트를 출시합니다.
- 공식 주변 장치 및 드라이버 라이브러리를 확충합니다.
- Raspberry Pi Bluetooth 페어링을 위한 BlueZ 프로토콜을 구현합니다.
- SoC 기반 ASR(CPU KWS/VAD)을 지원하는 ALSA HAL 계층을 개발합니다.
- USB/AT 인터페이스를 통해 4G Cat.1 셀룰러 모듈을 통합합니다.
- 서드파티 클라우드 연결(Doubao, Coze, Alibaba Bailian)을 지원합니다.
- ASR-LLM과 Netease Cloud Music 서비스의 통합을 활성화합니다.

**주변 장치 및 드라이버 확장:**
- 여러 T5AI DVP 비디오 센서 드라이버와 애플리케이션 예제를 통합해 비디오 캡처 및 처리 기능을 강화했습니다.
