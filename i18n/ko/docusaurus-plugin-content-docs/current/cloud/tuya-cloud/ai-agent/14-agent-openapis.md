Agent OpenAPIs는 자체 플랫폼 또는 소프트웨어로 Tuya-powered AI 에이전트를 통합 할 수 있습니다. Tuya Developer Platform에 에이전트를 구축하고 자신의 제품에서 사용하려는 경우 Tuya의 OpenAPI 엔드포인트를 통해 에이전트의 데이터를 액세스합니다.

플랫폼의 개방 기능은 개선을 유지합니다. 최신 업데이트에 대한 플랫폼 문서보기.

## 사용법
Tuya Developer Platform에서 OpenAPI 액세스 관리 [Cloud Development](https://platform.tuya.com/cloud) 섹션에서 클라우드 프로젝트를 만들고 API 통화를 만들기 전에 관련된 서비스에 가입하십시오. 에이전트 API는 클라우드 프로젝트에 의해 발행 된 액세스 키와 인증.

## 빌링
기능 수수료는 없습니다.

API 통화 중에 소모된 에이전트 토큰은 평소처럼 미터로 계산됩니다. 청구 규칙의 경우 [Agent 계량 및 빌링] (https://developer.tuya.com/en/docs/iot/ai-agent-price?id=Kegb2s2shaj4d#title-3-Model%20fees)를 참조하십시오.
