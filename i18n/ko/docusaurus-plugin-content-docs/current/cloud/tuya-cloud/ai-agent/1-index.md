Tuya [AI Agent Dev Platform] (https://platform.tuya.com/exp/ai)는 대형 모델 위에 AI 에이전트를 구축하고 스마트 장치를 통해 관리 할 수 있습니다. 당신은 플랫폼에 에이전트를 구성, 다음 앱 및 장치에 게시하거나 API 및 SDK를 통해 자신의 시스템에 통합.

## 왜 Tuya AI Agent Dev 플랫폼 사용
- ** 원 스톱 개발 플랫폼 ** - 필요한 기능 및 지원 기능은 추가 개발없이 사용할 수 있습니다.
-**Hallucination control** — IoT에서, AI 복도는 심각한 문제를 일으킬 수 있습니다. 플랫폼은 일괄 처리 테스트, 워크플로우 및 Retrieval-augmented Generation (RAG)를 사용합니다.
- **Things data model Agent** - 에이전트가 디바이스에 직접 이야기하므로 장치 제어에 큰 모델을 배선의 복잡한 작업을 건너뛸 수 있습니다.
- **Multi-model 협업 ** - Tuya의 작은 모델과 플랫폼 쌍의 큰 모델은 빠른 응답, 더 효율적인 상호 작용, 그리고 낮은 장치 제어 비용.
-**Open and extensible** - 사용자 정의 개발이 지원되므로 제품으로 에이전트의 기능을 확장할 수 있습니다.

## 참조
- [AI Agent Dev Platform] (ai-agent-dev-platform) - 에이전트를 만들고 모델, 프롬프트 및 응용 프로그램을 구성
- [Workflow Management](workflow-management) - 시각적 작업대에 관현된 에이전트 논리
- [Variables Management](variables-management) - 에이전트 메모리 및 개인화
