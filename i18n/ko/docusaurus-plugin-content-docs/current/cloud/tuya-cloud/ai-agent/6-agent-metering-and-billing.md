## 크레딧
플랫폼은 ** 공인 청구 기관으로 **를 사용합니다. 가치 추가 서비스를 통해 신용을 구입하고 신용은 청구 가능한 항목의 실제 사용에 따라 공제됩니다.

## 빌링 사이클
모든 청구 가능한 항목은 매일 청구됩니다. 플랫폼은 실제 사용에서 매일 소비 한 크레딧을 계산합니다. 송장은 일반적으로 계산 주기의 끝 후에 2 일, 체계 가공에 정확한 타이밍 주제로 생성합니다.

## 수수료 구조
대리인은 pay-as-you-go 기초에 위탁됩니다:

```text
Total fee = Model fee + AI voice fee + Extended capability fee − Waived fee
```

각 용어는 아래와 같습니다.

## 모델 요금
모형 서비스는 토큰 사용법에 위탁됩니다:

```text
Model fee = Token usage × Unit price of tokens
```

A ** token**는 큰 언어 모델에서 처리하는 기본 텍스트입니다. 모델은 일련의 토큰으로 입력 텍스트를 분리하고 프로세스를 분석합니다. 토큰은 단어, 문자, 하위 단어 조각 또는 기타 텍스트 세그먼트가 될 수 있습니다. 세그먼트는 모델의 Tokenizer에 따라 다릅니다. 따라서 토큰은 모델 아키텍처 사이에서 다릅니다.

다른 모델에 대해 [Available Models](https://platform.tuya.com/exp/model)를 참조하십시오.

## AI 음성 요금
AI 음성은 음성 입력 (자동 음성 인식, ASR) 및 음성 출력 (텍스트 - 투 - 슬립, TTS)를 포함합니다:

```text
ASR fee = ASR unit price × Input audio duration
TTS fee = TTS unit price × Output character count
```

- **ASR**는 오디오 신호를 분석하여 음성을 변환하는 자연적 음성 입력을 인식하고 이해합니다.
- **TTS**는 음성 출력으로 텍스트를 변환, 인간의 연설을 시뮬레이션합니다.
