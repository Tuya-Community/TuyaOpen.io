사용자 정의 MCP 서비스는 MCP 서버이며 Tuya 플랫폼에 등록하여 자신의 도구를 에이전트에 노출시킵니다. 이 가이드는 생성, 구성, 디버깅, 에이전트에 하나 추가를 통해 걸어.

## 사용자 정의 MCP 서버 만들기
1. [Tuya Developer Platform] (https://platform.tuya.com/)에 로그인하십시오.
2. [**MCP Management**](https://platform.tuya.com/exp/ai/mcp) >**Custom MCP Service**로 이동하면, **사용자 지정 MCP**을 추가할 수 있습니다.

![사용자 지정 MCP 항목 추가](https://images.tuyacn.com/content-platform/hestia/17552251294ef4fcc8a0a.png)

3.**Sign up MCP Server** 대화 상자에서 중국과 영어로 서비스 이름과 설명을 입력하고 아이콘으로 이미지를 업로드한 다음 **Confirm**을 클릭하여 저장합니다.

![https://images.tuyacn.com/content-platform/hestia/17552253115b7d3028283.png를 호출](https://images.tuyacn.com/content-platform/hestia/17552253115b7d3028283.png)

## 사용자 정의 MCP 서버 구성
:::대여
사용자 정의 MCP 서비스는 여러 데이터 센터를 통해 배포되는 경우, 모든 데이터 센터에 일관성있는 서비스 버전과 도구 구성을 유지합니다. Inconsistencies는 에이전트 관현을 방해하거나 기능 장애를 일으킬 수 있습니다.
:::

1. MCP 서버를 만들면, 플랫폼은 ** 서비스 세부 사항** 페이지로 리디렉션합니다.
2. ** 서비스 액세스 구성 관리 ** > ** 데이터 센터**, click **Add Data Center** on the right, select a data center, then click **OK**.

![사용자 지정 MCP 서버에 데이터 센터 추가](https://images.tuyacn.com/content-platform/hestia/1755225536581a0ae9478.png)

3. 선택된 데이터 센터를 클릭하여 ** Endpoint**, **Access ID** 및 **Access Secret**를 참조하십시오. 이 값을 로컬 장치에 복사 — 당신은 나중에 MCP SDK를 실행할 때 필요합니다. 더 많은 정보를 원하시면, [GitHub 소스](https://github.com/tuya/tuya-mcp-sdk.git)에서 **README**를 참조하십시오.

![Endpoint, Access ID 및 액세스 비밀](https://images.tuyacn.com/content-platform/hestia/175522559927d1caf4f12.png)

## MCP 서버 액세스
다운로드 MCP SDK 에서 [GitHub](https://github.com/tuya/tuya-mcp-sdk.git) 그리고 문서를 읽습니다. SSE 모드만 지원됩니다.

![MCP SDK](https://images.tuyacn.com/content-platform/hestia/1755154107774314342c7.png)

## 실행 및 MCP 서버 디버그
사용자 정의 MCP 서버 작업을 확인하려면, 실행 및 에이전트 환경에서 디버그.

### 실행 및 디버그
1. 선택한 데이터 센터에서 MCP 서버의 서비스 상태를 확인하십시오.

![MCP 서버 서비스 상태](https://images.tuyacn.com/content-platform/hestia/1755225694a9430fec3a3.png)

2. **Tool** 탭에서 MCP 서버의 사용 가능한 도구를 볼 수 있습니다.

![Available 도구 탭](https://images.tuyacn.com/content-platform/hestia/17552257539b261737630.png)

3. 테스트하려는 도구에서 ** Test Run**를 클릭하십시오.

![도구에서 테스트 실행](https://images.tuyacn.com/content-platform/hestia/1755225801672df842cdd.png)

4. **테스트 실행** 창에서, click **Run**. * 제출이 완료되면 ** 왼쪽 모서리에 나타납니다, MCP 도구는 성공적으로 debugged.

![테스트 실행 창에서 전달](https://images.tuyacn.com/content-platform/hestia/175522586669f31b0a863.png)

### 에이전트에 서버를 추가
1. [**My Agent**](https://platform.tuya.com/exp/ai) 페이지로 이동하고 ****Operation** 열에서 ** 개발
2. **01 모델 구성** > **Skills 구성**, **Plugin**을 찾아 오른쪽에 **+**을 클릭합니다.

![Plugin은 Skills 구성 아래 버튼 추가](https://images.tuyacn.com/content-platform/hestia/1759024307af722e75e90.png)

3.**Add Tool** 페이지에, **MCP** 탭을 선택하고, **Custom MCP Service**를 클릭하고, MCP 서버를 에이전트에 추가합니다.

![ MCP 탭으로 도구 페이지를 추가](https://images.tuyacn.com/content-platform/hestia/1758895157942582117da.png)

이제 사용자 정의 MCP 서버의 개발 및 디버깅을 완료했습니다.
