팀이 수개월 동안 세심하게 다듬은 끝에 v1.5.0을 출시합니다! 이번 업데이트는 하위 아키텍처부터 사용자 경험까지 최근 가장 종합적인 업그레이드라고 할 수 있으며 모든 세부 사항에 팀의 노력을 담았습니다. TuyaOpen 프로젝트를 더 재미있고 풍부하게 만들어 준 활발한 커뮤니티와 개발자 여러분의 훌륭한 제안에도 감사드립니다. 커뮤니티 개발자 [HangYongmao](https://github.com/HangYongmao)가 오픈 소스 공동 제작에 참여해 재미있는 게임 데모를 만든 것을 보게 되어 팀도 특히 기쁩니다.

### 💪 T5AI 플랫폼: 성능 도약과 하드웨어 생태계 확장

**이번 주요 업데이트:**
- **멀티코어 성능 업그레이드**: Tuya T5 칩이 이제 SMP(Symmetric Multi-Processing) 아키텍처를 완전히 지원합니다. 멀티코어 연산 성능을 크게 끌어올려 시스템 동시성과 성능을 향상하며 고부하 및 멀티태스크 시나리오에 적합합니다.
- **MCP(Multimodal Control Platform) 서비스 공식 출시**: TuyaOpen 디바이스를 Tuya Cloud에 연결하면 개발자가 클라우드에서 맞춤형 MCP 서비스를 게시하고 연결할 수 있습니다. 공식 프리셋과 사용자 지정 확장을 지원해 Agent와 IoT 디바이스의 상호 작용 기능을 크게 확장합니다.
- **하드웨어 생태계 지속 확장**: `TUYA_T5AI_Pocket`, `TUYA_T5A_Core`, `WAVESHARE_T5AI_TOUCH_AMOLED_1_75` 등을 포함한 여러 공식 및 생태계 개발 보드 지원을 추가해 더 많은 애플리케이션 시나리오를 지원하고 개발자가 유연하게 선택할 수 있도록 했습니다.
- **혁신적인 애플리케이션 예제**: 새로운 `tuya_t5_pocket` 게임 콘솔 애플리케이션을 출시해 멀티모달 상호 작용, 그래픽 표시, 엔터테인먼트 애플리케이션에서 T5AI 플랫폼의 강력한 기능을 보여 주고 임베디드 개발의 창의적인 가능성을 확장했습니다.
- **주변 장치 및 드라이버 확장 업그레이드**: 이번 버전은 여러 T5AI DVP 비디오 센서 드라이버, ws2812 등 RGB LED 드라이버, IR 적외선 리모컨 송수신기 등 다양한 주변 장치와 드라이버의 지원을 추가하고 최적화했습니다. 개발자는 센서, 디스플레이, 조명, 적외선 등 다양한 주변 장치를 쉽게 통합할 수 있습니다.
- **드라이버 생태계 지속 성장**: 공식 팀과 커뮤니티가 새로운 드라이버를 계속 기여해 더 많은 대중적이고 혁신적인 하드웨어를 지원합니다. 오디오/비디오 캡처, 디스플레이 제어, 스마트 홈, 엔터테인먼트 상호 작용 등 다양한 영역에서 제품 아이디어를 빠르게 구현할 수 있는 드라이버와 애플리케이션 예제를 찾을 수 있습니다.

# Tuya 플랫폼, MCP 통합!
Tuya Intelligent Agent Development Platform은 이제 MCP Server 통합 기능을 완전히 지원합니다. 공식 MCP Server 또는 직접 개발한 MCP Server를 통합하면 Agent와 서드파티 서비스 및 IoT 디바이스 사이의 상호 작용 기능을 크게 확장할 수 있습니다. 이는 대규모 언어 모델에 물리적 세계를 인식하고 실행할 수 있는 "눈, 팔, 다리"를 장착하는 것과 같습니다. LLM을 통한 지능형 의사 결정을 구현하고 실제 디바이스 및 서비스와 효율적이고 안전하게 상호 작용해 AI와 물리적 시스템을 연결하는 지능형 다리를 구축할 수 있습니다.
Tuya MCP 기술의 장점
- IoT 디바이스 생태계에 맞게 설계: Tuya 생태계 디바이스는 플러그 앤 플레이 방식이므로 Agent에 MCP Server를 추가하기만 하면 즉시 사용할 수 있으며 다양한 IoT 시나리오에 자연스럽게 통합됩니다.
- 다양한 MCP 서비스 통합 지원: 공식 프리셋 MCP Server뿐 아니라 개발자의 MCP 서비스 맞춤 확장도 지원해 풍부한 서비스 생태계와 개인화된 통합을 결합할 수 있습니다.
- 더 간단한 개발 통합: 플랫폼에 서비스를 한 번 등록하고 경량 SDK를 통합하면 여러 지역에서 MCP Server에 빠르게 접근하고 배포할 수 있습니다.
- 글로벌 서비스 배포 지원: 전 세계 5개 주요 지역의 서비스 연결을 지원하고 인접 지역의 낮은 지연 시간 접근을 제공해 각 지역의 비즈니스 배포 및 규정 준수 요구 사항을 충족합니다.
- 안전하고 안정적인 장기 연결 통신: WebSocket 프로토콜을 기반으로 여러 지역에 안전한 장기 연결을 구축해 데이터 전송의 기밀성, 무결성, 가용성을 보장합니다.

# TuyaOpen SMP 아키텍처! SMP 아키텍처란 무엇이며 성능을 어떻게 개선하나요?
![AMP vs SMP](https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcQIGZ1BIgEvkdELaNGGX_P2SoDTFdHkpTPPiA&s)
  
AMP(Asymmetric Multi-Processing)와 SMP(Symmetric Multi-Processing)는 멀티코어 프로세서에서 사용하는 두 가지 일반적인 아키텍처입니다.

- **AMP(Asymmetric Multi-Processing)**: 각 코어가 서로 다른 운영 체제나 작업을 실행할 수 있으며 코어 간 리소스 할당과 스케줄링이 비교적 독립적입니다. 실시간성 또는 보안에 특별한 요구 사항이 있는 시나리오에 적합하지만 개발 및 리소스 관리의 복잡도가 높습니다. 예를 들어 한 코어는 Linux를 실행하고 다른 코어는 RTOS를 실행할 수 있으며 서로 영향을 주지 않습니다.

- **SMP(Symmetric Multi-Processing)**: 모든 코어가 동일한 운영 체제를 실행하고 시스템이 작업을 각 코어에 자동으로 분배합니다. 코어의 상태가 동일하고 리소스를 공유하므로 개발자가 특정 작업이 어느 코어에서 실행되는지 신경 쓸 필요가 없어 고동시성 및 멀티태스크 시나리오에 적합합니다.

**간단히 말하면**: AMP는 더 유연하지만 복잡해 특수한 요구 사항에 적합하고, SMP는 사용하기 쉬워 대부분의 범용 멀티코어 애플리케이션에 적합합니다. T5AI v1.5.0은 SMP 아키텍처를 채택해 멀티코어 개발을 더 간단하고 효율적으로 만듭니다!

**TuyaOpen의 SMP 아키텍처는 개발자에게 무엇을 의미하나요? 개발 방식을 바꿔야 하나요?**
> 요약: v1.5.0은 개발을 더 효율적이고 강력하게 만들지만 개발 습관과 코드 구조를 크게 변경할 필요는 없습니다. 새 기능과 멀티코어 모범 사례에 집중하면 업그레이드의 이점을 쉽게 누릴 수 있습니다.

- **더 원활한 개발 경험**: SMP 멀티코어 지원과 하드웨어 생태계 확장을 통해 성능 병목을 걱정하지 않고 고동시성 멀티태스크 애플리케이션을 쉽게 개발할 수 있습니다. 기존 싱글코어 코드는 크게 수정할 필요가 없으며 시스템이 멀티코어 리소스를 자동으로 스케줄링합니다. 멀티코어 잠재력을 더 활용하려면 멀티스레딩/멀티태스크 프로그래밍(RTOS 태스크, LVGL 멀티스레드 렌더링 등)으로 더 높은 성능을 구현할 수 있습니다.
- **API 호환성 보장**: 대부분의 API는 이전 버전과 호환되므로 기존 프로젝트를 원활하게 업그레이드할 수 있습니다. 새 하드웨어와 새 드라이버 접근 방식도 이전과 일관됩니다.
- **더 넓은 창의적 공간**: LVGL 듀얼 버전, 풍부한 주변 장치 및 게임 애플리케이션을 활용해 더 혁신적인 방식을 시도할 수 있습니다. 공식 예제를 바로 재사용하거나 새 드라이버와 기능을 기반으로 자체 애플리케이션을 개발할 수 있습니다.
- **대규모 리팩터링 불필요**: 이미 T5AI 기반 프로젝트가 있다면 v1.5.0으로 업그레이드한 뒤 대규모 코드 리팩터링을 진행할 필요가 없습니다.
- **권장 사항**: 멀티코어와 새 하드웨어 기능을 최대한 활용하려면 RTOS 태스크, 세마포어, 큐 및 기타 멀티코어 동시 프로그래밍 방식을 학습하고 사용하세요. 공식 멀티코어 예제와 문서를 참고하세요.
