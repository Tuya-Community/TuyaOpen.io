TUYAOPEN CORE / 涂鸦云 SDK 库

TuyaOpen Core.

任意平台， 一套库连接涂鸦云。

TuyaOpen Core 是一个轻量级 C SDK 库，可加入任意设备工程或平台，连接涂鸦云，并提供三个能力 API：IoT、AI Agent 和 P2P。无需更换系统或重写代码，只需链接这套库。

了解三个能力 API查看 GitHub

支持 Linux、ESP-IDF、RT-Thread、Zephyr、NuttX 等

01 / 适配任意平台

任意平台， 一套库接入。

TuyaOpen Core 可运行在任意操作系统或厂商 SDK 上：Linux、ESP-IDF、RT-Thread、Zephyr、NuttX 等。保留现有工具与代码，只需实现薄薄的平台适配层并链接库。

一套 SDK 库，通过薄薄的适配层接入你的平台。

02 / 三个能力 API，按需使用

一次连接， 按需调用 API。

一条通往涂鸦云的安全连接，提供三个能力 API：IoT 负责设备连接，AI Agent 负责云端智能，P2P 负责实时媒体。可任意组合。

04 / 如何接入

系统中的一个库。

把库链接进现有工程，通过薄薄的平台适配层使用系统服务——无需更换操作系统。

05 / CORE 与 TUYAOPEN

只要库，或用完整框架。

Core 是面向现有平台的 SDK 库；完整 TuyaOpen 是含平台适配、组件与工具的完整框架。两者连接同一个涂鸦云。

加入 SDK 库

TuyaOpen Core

适合已有工程：把库链接进现有平台，直接开始调用 API。

使用完整框架

TuyaOpen

适合全新工程：完整框架内置操作系统层、驱动层与应用示例，开箱即用，快速开发。
