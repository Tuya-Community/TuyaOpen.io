智能体计量计费

本文介绍智能体的各计费项及其计算方式。

价格会变，本页是镜像

权威来源是涂鸦开发者平台的 AI 计费规则。下面的表格同步自该页面，同步时间 2026-09-02。若要写进合同或成本测算，请以官方页面为准。

资源点​

平台使用 资源点 作为统一的计费单位。需先通过增值服务购买资源点，后续根据计费项的实际消耗量扣除对应资源点。

计费周期​

各计费项均按天计量，平台按照实际消耗量结算每天产生的资源点。账单出账时间通常在当前计费周期结束后两天，具体出账时间以系统为准。

费用构成​

智能体采用按需计费模式，遵循公式：

总费用 = 模型费用 + AI 语音费用 + 拓展能力费用 − 减免费用

各项费用说明如下。

模型费用​

模型服务根据模型的 Token 使用量计费：

模型费用 = Token 使用量 × 模型单价

在大语言模型中，Token 是文本处理的计量单位。模型通常将输入文本分解成一系列 Token，然后对这些 Token 进行处理和分析。Token 可以是单词、字符、子词片段或其他形式的文本片段，具体划分方式取决于模型使用的分词算法，因此 Token 的计算和处理方式会随模型架构和设计而不同。

如何区分模型类型，可参考 可用模型。

AI 语音费用​

AI 语音分为语音输入（Automatic Speech Recognization，ASR）和语音输出（Text-to-Speech，TTS）两部分：

ASR 费用 = ASR 单价 × 输入音频时长
TTS 费用 = TTS 单价 × 输出音频字符数
  • ASR：能够识别和理解人类的自然音频语言输入的技术，通过分析和处理语音信号，从而实现将音频转化为文本。
  • TTS：能够将文本转换成语音输出的技术，模拟人类进行朗读，从而实现将文字信息转变为音频信息。

减免费用​

如果智能体投放到设备进行直连，存在以下费用减免。

AI 基础减免​

若在开发产品时已开启 AI 智能体接入 高级功能，设备每日产生费用消耗时将会减免掉一定额度。当减免额度用尽后，每日的超量消耗将进行计费。

订阅模式减免​

若将对应产品加入到 订阅模式，涂鸦会提供设备端统一的订阅套餐、权益发放、使用量统计等。在 AI 基础减免之外，产品可获得继续减免，最终实现全额减免。
